A /24 subnet

A /24 is the block most people mean by a subnet on a LAN: 256 addresses, 254 usable hosts, mask 255.255.255.0. The /24s column of the table is 1 for this row, because the block is exactly one /24. 192.168.1.0/24

Subnet mask for /23

A /23 joins two /24s. It has 512 addresses and 510 usable hosts, and the mask is 255.255.254.0. The network address must be even in the third octet: 10.0.0.0/23 runs from 10.0.0.0 through 10.0.1.255. Writing 10.0.1.0/23 names the same block; the network address is still 10.0.0.0.

A /26 subnet

A /26 has 64 addresses and 62 usable hosts. The mask is 255.255.255.192. Four of them fill a /24, starting at .0, .64, .128 and .192. A request for 50 hosts rounds up to this size. 10.0.0.0/26

A /27 subnet

A /27 has 32 addresses and 30 usable hosts. The mask is 255.255.255.224, and eight /27s fit in a /24. It is a common size for a small office or a cloud subnet that needs more than a /28. 10.0.0.0/27

Subnet for /29

A /29 has 8 addresses and 6 usable hosts. The mask is 255.255.255.248. The block starts on a multiple of 8, which is why 192.168.1.8/29 covers .8 through .15. It is a usual size for a small link or a handful of servers.

A /30 subnet

A /30 has 4 addresses and 2 usable hosts. The mask is 255.255.255.252. That is the classic point-to-point size: one address for each end of the link, plus the network and broadcast addresses. 10.0.0.0/30

A /31 subnet

A /31 has 2 addresses and both are usable. The mask is 255.255.255.254. RFC 3021 uses it on a point-to-point link so neither address is spent on a network or broadcast address. 10.0.0.0/31

Using the tables

To size a subnet, find the first row whose usable hosts cover what you need: 50 hosts need a /26 (62 usable). To find the network an address belongs to, take the block size from the mask octet table and round the address down to a multiple of it: 192.168.1.77/27 has block size 32, and 77 rounds down to 64, so the network is 192.168.1.64/27. The subnetting tutorial explains each step, and the VLSM calculator does it for a whole list of subnets. The same prefix table is on the Subnet calculator when you type an address.
