What these tools do

Aggregation (route summarization) merges adjacent and overlapping blocks into the fewest prefixes that cover the same addresses, the list you would advertise from a router or put in a firewall object group. Supernet finds the single shortest prefix that holds everything; it is often broader than the inputs, and the tool reports how many extra addresses it pulls in. Overlap detection lists every pair where one block sits inside another, which is how duplicated routes and clashing VPC ranges show up.

How to summarize routes by hand

  1. Write the third octets of 10.0.0.0/24 to 10.0.3.0/24 in binary: 00000000, 00000001, 00000010, 00000011.
  2. The first 6 bits of that octet are the same in all four, so the common prefix is 8 + 8 + 6 = 22 bits.
  3. The summary is 10.0.0.0/22. It covers exactly the four /24s because all four are present and the block starts on a multiple of four.

If one of the four were missing, a single /22 would also cover the missing /24. Aggregation keeps the result exact; the supernet does not. Check any block in detail with the subnet calculator.

Questions

What is the difference between aggregation and a supernet?

Aggregation merges networks into the fewest CIDR blocks that cover exactly the same addresses. A supernet is one block that covers every input, and it may also cover addresses that were not in the list.

How do I summarize 10.0.0.0/24 through 10.0.3.0/24?

The four /24s are contiguous and start on a multiple of four, so they summarize to 10.0.0.0/22.

Why don't 10.0.1.0/24 and 10.0.2.0/24 merge into a /23?

A /23 must start on an even third octet. 10.0.1.0/24 and 10.0.2.0/24 are adjacent but straddle a /23 boundary, so the smallest single block that holds both is 10.0.0.0/22, which also includes 10.0.0.0/24 and 10.0.3.0/24.

How do I convert an IP range to CIDR?

Starting at the first address, take the largest block that starts there and does not pass the end of the range, then repeat from the next address. 192.168.1.10 to 192.168.1.20 becomes 192.168.1.10/31, 192.168.1.12/30, 192.168.1.16/30 and 192.168.1.20/32.

What does it mean when two subnets overlap?

CIDR blocks either do not overlap at all or one contains the other. An overlap usually means a duplicate route, a VPC peering conflict, or a subnet that was carved twice.
